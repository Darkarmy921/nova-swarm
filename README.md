NOVA SWARM is a neon twin-stick arena survival shooter: pilot the starship Kestrel, blast escalating waves of swarm ships, chain kills into an x8 combo, detonate Nova bombs, and survive the Hollow Herald every fifth wave. Pure canvas 2D and synthesized WebAudio — zero libraries, zero network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, mouse to aim, hold left click to fire, Space/Shift to dash, E for a Nova bomb, P to pause, M to mute.
